# RF4 Server · 俄钓 4 单机版服务端

俄钓 4（Russian Fishing 4）单机版服务端分发包。独立端和 Steam 端都可以用，解压后即可离线畅玩。

## 下载

| 文件 | 说明 |
| --- | --- |
| `rf4_server_V5.7z` | 最新版（推荐） |
| `rf4_server.7z` | 早期版本，仅作留档 |

## 环境要求

- 客户端版本：**4.0.25034**（只针对这个版本；官方后续更新可能失效）
- 解压路径**不要带中文或空格**

## 使用步骤

1. 下载 `rf4_server_V5.7z` 并解压到本地目录（路径不要含中文、空格）。
2. 建议先备份客户端目录，避免官方更新后无法回退。
3. 启动包内服务端，再打开俄钓独立端或 Steam 端；也可以复制可执行文件的完整路径，在浏览器中打开客户端。
